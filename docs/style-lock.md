# The style lock

Write this file before you generate a single object. It is the cheapest thing in the whole
method and it is the difference between a set and a pile.

Ten objects each generated in their own style give you ten fine objects and one incoherent
game. That sentence is already in [../404.md](../404.md) and on its own it is not enough,
because "use one style" is a hope until it is a file that every generating agent is handed.

## What goes in it

**One style sentence.** Not a mood board, not three adjectives. One sentence naming the
material, the finish and the treatment, written so that two people reading it build the same
object. Reuse it verbatim for every object in the set.

**The palette, as exact hex values.** Six to twelve of them, each with a note saying where it
belongs. An agent given "warm timber tones" will invent a different brown every time. An agent
given `0xa9784f  warm timber, crates and counters and framing` will not.

**Real sizes for the common objects.** A counter is 0.9 m high, a stool is 0.42 m, a crate is
0.4 m across. Sizes drift more than colours do, and a set that drifts does not assemble.

**The material names**, taken from [asset-contract.md](asset-contract.md), not restated from
memory. `surfaces.js` reads these. A style file that lists its own shortened version of that
list will drift from it, which has already happened once.

## Template

```markdown
# <project> — the locked style

> <one sentence: what these objects are made of, how they are finished, how they are treated.>

| role | hex | where it belongs |
|---|---|---|
| ... | `0x......` | ... |

## Fixed decisions
- Metres. <object> is <n> m. <object> is <n> m.
- Base at y = 0, centred on x and z, front faces +Z.
- Flat colours with sensible roughness; surfaces are applied at load time.
- Material names from the contract's list, not a shortened one.
```

## Why it is worth the ten minutes

In one run of this method, twenty six objects were generated by nine agents that could not see
each other's work, each writing three candidates and choosing one. The only thing they shared
was a file like the one above. The set reads as a single game. Nothing else in the process
would have produced that, because no agent could see what any other agent had made.
