# Running 404 with your own agent

404 generates 3D as **code**: one JavaScript module per object that returns a Three.js `Group`.
No mesh files, no downloads, nothing to install on a GPU.

There is no service to call and no key to buy. Your agent does the generating. What this repo
gives you is the method and the two checks that make it reliable.

---

## The method

**One reference image per object. Three independent attempts at geometry. Verify. Pick by eye.**

That is all of it.

### 1. A reference image, not a sentence

Generating from a picture beats generating from a description by a wide margin, and it is the
cheapest quality win available.

A name is not a description. Asked for "a shop front" a model invents everything and mostly
invents badly. Measured: "a shop front" failed outright, while "a solid one-storey block with a
striped awning slab and a shutter recessed into the wall" gave usable geometry on 14 of 16
attempts.

**Use one style for the whole set.** Ten objects each generated in their own style give you ten
fine objects and one incoherent set. Fix a single style sentence, reuse it for every object, and
generate the set in one pass.

Any image source works. [gen/README.md](gen/README.md) covers what makes a usable reference, and
`gen/concept.py` is the [Atlas](https://atlas.design) path if you have a key. You do not need one.

### 2. Three independent attempts

Independent means different construction strategies, not three edits of one file:

- one assembled from primitives: Box, Cylinder, Sphere, Cone, Torus
- one built from profiles: `ExtrudeGeometry` or `LatheGeometry` swept along an axis
- one with a different part breakdown, or a different reading of the reference

Each one written to the contract in [docs/asset-contract.md](docs/asset-contract.md).

### 3. Verify

```bash
node --check <each candidate>
node harness/verify.mjs <dir>
```

It renders every candidate from four sides under identical light, measures it, and writes
`_verify/sheet.png`.

The check that earns its place is the fourth view. An object modelled from the one angle its
reference showed is a featureless box from behind, and every screenshot hides it, because every
screenshot is taken from the good side.

It also catches: doesn't parse, doesn't return an `Object3D`, degenerate bounds, an implausible
real-world size, a base that isn't at `y = 0`, and a triangle count that has run away.

### 4. Pick by eye

Look at the sheet and choose. **Not by triangle count.** A scoring heuristic once picked a broken
planter at 265,265 triangles over a correct one at 3,880. The numbers tell you what is broken.
They cannot tell you what is good.

If all three attempts are poor, the reference is the problem rather than the generation.

---

## Why three

Measured on ten objects. One arm got a single attempt. The other got three plus a syntax check, a
four-sided render and a choice between them. Same model, same references, same output contract.

The second arm won on essentially every object, and the difference was entirely the loop.

Two of the errors it caught in one run, neither of which is a syntax error and neither of which
survives being looked at: an inverted rotation sign that flung a car's windscreen off into space,
and a water tank built 20% too tall because the reference photograph foreshortened its base.

## Using what comes out

```js
import { ASSET } from './harness/assetlib.js';
const car = await ASSET('./assets/hero_coupe.js', { height: 1.44 });
scene.add(car);
```

Copy `harness/assetlib.js` rather than writing your own. The comment at the top of it explains
what that costs: it silently destroyed an entire asset pack across four builds before anyone
noticed.

Plain Three.js otherwise, with no dependency on anything else here.

## Before you start

Read [docs/traps.md](docs/traps.md). Bugs specific to this domain that produce wrong output
**silently**: nothing throws, nothing warns, and the code reads correctly. You will not catch
them by testing the way you normally test.

And run this once, so you know the verifier is actually protecting you:

```bash
node harness/selftest/run.mjs
```

It runs the verifier against assets that are deliberately broken in known ways and asserts each
one is caught. A check nobody has seen fail is decoration.
